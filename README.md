A single deadpan weather forecast for Blorfton, a city that does not exist: steady rain of warm gravy, a low of 41, and a 90 percent chance your umbrella comes back tasting of beef. Deterministic, Python 3 standard library only, no network.

## Run it

```sh
python3 main.py
```

`main.py` writes one line of at most 160 characters to `/output/entry.txt`.
